# 我的追番列表

- 大家好啊，虽然不知道做这个的意义是什么，但是总感觉把自己看过的番列出来还挺爽的。
- 一方面可以罗列整合，另一方面也可以看看自己的浓度有多高。。
- 同时在每个番剧下我可能会加上一些小评价。
- 本人很杂食！基本什么类型都有看！！望周知
---
# 分类
- 我将会把追的番根据观看进度分为 #观看状态：看完 #观看状态：中道崩殂 #观看状态：正在看 
	- 没看的（或者我自认为看了一点点但不算看的）一般将不列入（除非我想评价）
- 还会锐评（仅代表个人喜好） #评级：夯 #评级：顶级 #评级：人上人 #评级：NPC #评级：拉完了
	- #评级：夯 是我最喜欢的番，望周知
- 注意， #厕纸 标签不代表番剧烂，仅代表某种程度上有点烂大街的感觉
- 还会给每个番打上通常的标签（自认为）
- 如果这部番看的时间太久，我已经基本忘记的话，我会打上 #记忆程度：不记得了
